# Киносезон

Каталог фильмов сезона через их путь по фестивалям и премиям: где фильм впервые показали, что он там получил и докуда дошёл — от Сандэнса и Канн до «Оскара».

Три сезона: 2024/25, 2025/26 и 2026/27 (идёт). В каждом пять фестивалей (Сандэнс, Берлинале, Канны, Венеция, Торонто) и пять премий следующего года (Critics' Choice, «Золотой глобус», BAFTA, Actor Awards, «Оскар»).

## Что лежит в папке

| Путь | Что это |
|---|---|
| `index.html` | Сама страница: код и оформление |
| `data/2024-25.js`, `data/2025-26.js`, `data/2026-27.js` | Данные сезонов: фильмы, события, программы, победители |
| `img/<сезон>/` | Постеры событий сезона |
| `img/trophy/`, `img/logo/` | Статуэтки и логотипы событий |
| `posters.json` | Постеры фильмов и номера IMDb, собранные заранее. Сначала пустой, его заполняет скрипт |
| `tools/build-seo.mjs` | Скрипт, который собирает текстовый список победителей внизу страницы |
| `tools/fetch-posters.mjs` | Скрипт, который собирает постеры через TMDB и номера IMDb через Викиданные |
| `.github/workflows/posters.yml` | Задача GitHub, которая запускает скрипт и сохраняет `posters.json` |

Страницу можно открыть и локально, двойным щелчком по `index.html`. Тогда постеры фильмов подгружаются из Кинопоиска и Википедии, а `posters.json` не используется.

## Как включить сайт

1. **Включить GitHub Pages**: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту страница будет доступна по адресу `https://<имя>.github.io/<репозиторий>/`.
2. **Получить ключ TMDB** (бесплатно): зарегистрироваться на themoviedb.org → Settings → API → запросить ключ для некоммерческого использования. Подойдёт любой из двух: «API Key» (короткий) или «API Read Access Token» (длинный).
3. **Положить ключ в секреты репозитория**: Settings → Secrets and variables → Actions → New repository secret. Имя: `TMDB_TOKEN`, значение: ключ.
4. **Запустить сбор постеров**: вкладка Actions → «Постеры из TMDB» → Run workflow. Задача пройдёт по всем фильмам (несколько минут), сохранит `posters.json` в репозиторий, и страница начнёт показывать постеры из него.

Дальше задача сама запускается раз в неделю и добирает постеры, которые появились в TMDB. Если включить при ручном запуске «Пересобрать все постеры заново», она обновит и уже найденные.

## Откуда страница берёт постеры фильмов

По порядку, пока не найдёт:

1. `posters.json` — то, что заранее собрал скрипт (TMDB, сначала русский постер, если его нет — основной).
2. Кинопоиск по номеру фильма (неофициальный сервис, может перестать работать).
3. Английская и русская Википедия, Викиданные.

Найденное запоминается в браузере посетителя.

## Ссылки на IMDb

В карточке фильма ссылка ведёт прямо на страницу фильма в IMDb, если известен его номер: из `posters.json` или из Викиданных. Иначе — на поиск IMDb по названию. С самого IMDb ничего не скачивается: его правила запрещают автоматический сбор данных.

## Как обновлять

- **Данные сезона** (новые номинанты, победители) — в `data/<сезон>.js`. После добавления фильмов запусти задачу «Постеры из TMDB» вручную, она найдёт постеры для новых.
- **Текстовый список победителей** внизу страницы (его читают поисковики) собирается из данных: после правки `data/` выполни `node tools/build-seo.mjs` и закоммить `index.html`.
- **Постер события** — положи картинку в `img/<сезон>/<событие>.webp`, где событие: `sundance`, `berlin`, `cannes`, `venice`, `toronto`, `critics`, `globes`, `bafta`, `actors`, `oscar`.
- **Цвета событий** — объект `PALETTES` в `index.html`, у каждого сезона своя палитра для светлой и тёмной темы.

Проверить, что скрипт видит все сезоны, можно без ключа: `node tools/fetch-posters.mjs --check`.
